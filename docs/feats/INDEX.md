# Feature spec index

Feature specs live in this directory, one file per feature, numbered
sequentially (`NNNN-slug.md`, zero-padded to 4 digits) in the order they
were drafted — the number is a permanent ID, never reused or resequenced
even if a spec is later dropped. Add a row here whenever a new spec file is
created, and keep the Status column in sync with the spec's own `Status`
line as it moves through its lifecycle (`proposed` → `in progress` →
`shipped` / `dropped`).
